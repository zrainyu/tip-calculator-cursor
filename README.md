# Tip Calculator

A small tip calculator for splitting a restaurant check. Enter the bill, choose a tip, and see what each person owes. Totals update as you type.

## How to run

Open `index.html` in a browser. There is no build step and no dependencies.

## Features

- Bill amount, tip percent, and number of people
- Preset tip buttons for 10%, 15%, 18%, and 20%, plus a slider from 0% to 30%
- Live tip amount, total, tip per person, and total per person, formatted to two decimals
- Validation that ignores an empty or negative bill, requires at least 1 person, and shows a short hint when input is invalid
- Dark mode toggle that remembers the choice in localStorage
- Layout that fits a phone screen
